# 发布 v1.3.0 直连安装包

## 1. 做了什么

为已经验证通过的 F8 本地直连版制作 `v1.3.0` 安装压缩包，并发布到 GitHub Releases。安装包包含最新托盘程序、CLI、源码、启动与自启脚本、README 和维护说明；Release Notes 单独说明了直连提速、文件夹与混合多选、安全加固和升级方法。

## 2. 为什么做

GitHub 主分支虽然已经是最新版，但普通用户通常从 Releases 下载。如果只更新代码、不更新安装包，下载页仍会把用户带回旧的右键菜单模拟版本，也无法获得刚修复的文件夹能力，因此必须发布一个不覆盖历史版本的新 Release。

## 3. 值得记住的决策、坑或技术点

- 沿用语义化版本并从 `v1.2.4` 升到 `v1.3.0`，因为本地直连属于明显的新能力，不是单纯的小修补。
- 不覆盖旧 Release，也不复用旧标签；历史版本继续保留，方便回退和比较。
- 安装包只放运行与维护必需文件，不携带本地日志、抓包、临时测试目录或未发布调查笔记。
- 上传前检查压缩包清单和 SHA-256，上传后再从 GitHub Release 元数据核对标签、目标提交、资源名称与摘要。

## 4. 一句话亮点

绿盾 F8 从“替你点菜单”正式进化为“直达官方申请”，文件夹、混合多选和安全保护一次装进 v1.3.0。
