# 完善英文 README

## 做了什么

新增了一份完整的 `README_EN.md`，并在中英文 README 顶部加入双向语言切换。英文版覆盖项目定位、适用条件、30 秒上手、F8 与 MCP 两种入口、Agent 自动续跑、安全边界、技术原理、CLI、兼容性、构建、故障排查、贡献方式和作者相关项目。

## 为什么做

仓库名称和 Topics 已经适合英文搜索，但默认内容几乎全是中文。英文用户或 AI 搜索即使找到了项目，也很难快速判断它是不是适用于 Tipray Green Shield、是否会绕过安全策略，以及怎样安装 MCP。英文 README 补齐了从“被搜索到”到“理解并放心使用”的中间环节。

## 值得记住的决策、坑或技术点

- 英文版按英文用户的阅读逻辑重新组织，不做僵硬的逐句翻译。
- `authorized decryption request`、`Tipray Green Shield`、`LdTerm`、`DLP`、`local MCP server` 等关键词都放在真实语义里，没有单独堆砌关键词。
- 开头先明确它不是通用解密器，也不会绕过权限和审批，避免英文语境下把项目误解成安全绕过工具。
- 所有命令、工具状态、文件夹限制和安装路径都与中文版及当前代码保持一致。
- 两种语言使用独立文件，后续修改功能时要记得同步更新两份说明。

## 一句话亮点

现在不论中文用户、英文用户还是 AI 搜索第一次进入仓库，都能迅速看懂它解决什么问题、为什么可信、如何马上使用。
